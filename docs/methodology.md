# Dota Captain Lab

A static composition calculator adapted from the compact table and comparison workflow of Riley31415's Wuthering Waves calculator. Open `dist/index.html` through an HTTP server; the worker needs HTTP. No install or build step is required.

The default catalogue contains 120 candidate drafts; the optional fixed-opponent example contains 240. Search screens 6,000 lineups, improves a bounded shortlist, and evaluates all 64 strategy combinations using DotaCaptain's native AI pick formula (`16286`, original internal function `A`). The catalogue value averages five native scores, each hero assessed in its assigned role beside the other four teammates. The arithmetic mean is this tool's aggregation, not an official team score. All component coefficients, caps, penalties and relationship qualifications remain unchanged. No custom weighted formula is used.

Filter, sort, pin up to four teams and inspect nearby hero replacements. General auto optimization uses balanced training screening, shortlist refinement, and separate evaluation as described below. Single-match optimization tests all 64 strategies exactly for the supplied opponent and configuration. Roles remain as assigned and items remain default.

The live draft assistant accepts 0–5 enemy picks and role-locked confirmed picks for your team. Native next-pick and next-ban values come from the original AI decision function (`16286`, internal `j`), without random selection variation. Pick suggestions additionally require an unfilled preferred role. Ban history distinguishes your earlier bans from opponent bans/unavailable heroes. Opponent pick values are separate estimates using their chosen plan and native captain personality. Confirming a suggestion records it in this calculator and refreshes recommendations; it never submits to DotaCaptain. Start an empty live draft to enter an ongoing match. The opponent's six strategy axes can be entered individually. Known enemy roles can override automatic assignments through the original native hard-role assignment function (`18155.HF`); role-default items follow the effective assignment.

Every hero uses the DotaCaptain draft page's role-aware default preset (`5092.z8`), in its original order. Enemy heroes use their automatically assigned roles and the same default preset function. There is no item editor or item optimizer.

The optional example opponent is Chaos Knight, Kez, Bristleback, Chen and Kunkka. The optional example catalogue has 1,440 saved scenario results: three enemy strategies on both sides for each of 240 drafts. Changing enemy picks or draft constraints requires a new search; new compositions must be tested to get simulation results. Hero substitutions preserve the current strategy and regenerate role-default items.

The original compiled public browser modules and data are embedded in `dist/engine.js`; `dist/source-manifest.json` records URLs and hashes. Simulator, AI draft and draft-page chunks were fetched again on 6 October 2026 and their hashes matched the inspected source. Two existing pure functions gained export names; their implementations were not modified. Tests compare results against the independently loaded original modules: two lineups on both sides (four match fixtures), native pick rankings, pick/ban selections under all four personalities, catalogue score aggregation, and all 64 configuration results.

Private server source, ranked hero profiles, organization modifiers and account comfort history are unavailable. Parity with live server matches has not been established. Search is bounded and cannot establish a global optimum. The simulator is deterministic for identical inputs; scenario wins are not statistical win probabilities. Native recommendations do not predict the opponent's randomized reply with certainty.

Draft information follows public modules 32354 (24 CM actions), 14822 (solo store), 13177 (PvP sync), and the draft page intel visibility flags. Confirmed heroes are visible after each pick. `pickPhaseReveal` contains the player’s own final five, not hidden enemy picks. A solo scout can reveal doctrine and captain style before draft; it does not reveal future heroes or guarantee final roles. PvP enemy plan/final role state is populated only when simulating or complete. The calculator starts with empty opponent slots, blank axes/style/side, and no comparison reference. Explicit scenario mode and role-inference permission distinguish assumptions from observations. Comparison references save the selected configuration and show differences in native points.

General ranking uses 120 candidate drafts, each evaluated on 256 profiles × both sides (61,440 weighted results). All 64 enemy strategies cross native-score shortlist and uniform preferred-role policies. Two complete 128-profile replication batches each cross every plan with both policies; common seeds and rules apply across candidates, but legal exclusions can change the actual opponents. Shortlist scores do not use the evaluated team as revealed enemies. Unknown roles vary over valid preferred-role assignments. Policy weights are an assumed benchmark, not measured population frequencies. The UI reports subgroup results, unique deterministic cases and replication rank ranges; these ranges are descriptive sensitivity, not confidence intervals. 128/512-profile re-tests extend the same stratification. Ranking remains bounded to the candidate catalogue and preferred-role opponent population.

General strategy optimization screens all 64 plans on 16 training profiles spanning both policies, then refines eight finalists plus the current plan on 128 training profiles. The winning training plan is evaluated with different scenario seeds on the selected evaluation bank (256 profiles by default); evaluation results never select the winner. Matching training/evaluation profiles are disclosed when fixed inputs collapse variability. The shortlist can miss the best strategy, evaluation can be worse than the previous configuration, and repeated user selection against a fixed evaluation bank can overfit it. Single explicit-match optimization still tests all 64 plans exhaustively.

Each detail page lists three strongest distinct suite opponents against its fixed displayed configuration. Deeper counter search screens up to 36 candidate lineups over three strategies, then tests all 64 strategies for four finalists on both sides. The result reports opponent wins and opponent NW lead from matches simulated with the selected team as the player, avoiding a player-side reversal. Ban priority counts exact found-lineup coverage, then native protection ban score; it does not imply that enemy replacements are prevented. Configuration edits and bans invalidate dependent results. Items remain native role presets.

Solo-doctrine sorting reweights existing scenarios using the public 97174.R0 base presets and 0/1/2-axis flips (35%, 48.75%, 16.25% under uniform random draws). It does not change the simulator. Hero policies remain hypothetical; this source-derived strategy prior is not an empirical distribution of actual Solo match outcomes.

Fresh searches return native-score candidates without automatically running a large simulation batch. Benchmark and optimize explicitly evaluate the chosen number of filtered teams, starting with one by default.
